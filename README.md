# AI Work Pet · 大肥鱼（DeepSeek）和白龙娘（GPT）

网页桌宠。已经做好两位：大肥鱼（DeepSeek）和白龙娘（GPT），之后是 Claude、Gemini、Grok。共用一个引擎，每个角色有自己的原画、绑定和动作。网页上可以随时切换。

## 怎么看

```
git clone https://github.com/hhxk233/ai-work-pet.git
cd ai-work-pet
python -m http.server 8000 --bind 127.0.0.1
```

打开 http://127.0.0.1:8000/ 。左上角切换大肥鱼 / 白龙娘（也可以直接开 `?pet=gpt`），底部按钮是她的全部动作，加左右走和自动闲逛。点她一下会跳，拖动换位置，右键或长按选动作。

`samples/` 里是同一套代码逐帧导出的样片。旧的 v04（P2L 播放器版）整套保留在 `legacy/v04/`。

## 白龙娘（GPT）

照着她 Live2D 设定图左上角那张 Q 版做的：白发、龙角、尖耳朵、花结发饰、一对小翅膀，尾巴盘在地上。

- **待机和走路**：呼吸、眨眼、转头；长发整片慢慢摆，翅膀随呼吸起伏、隔一阵扑两下，尾巴尖的小卷自己摆，尖耳朵偶尔抖一下，耳坠和呆毛跟着晃。裙子前面开口，走路时两只靴子在开口里交替迈步。
- **动作**（26 张姿势图）：

  | 动作 | 姿势顺序 |
  | --- | --- |
  | 吃小饼干 | 捧着看 → 咬一口 → 鼓着腮嚼 → 眯眼回味，两口 |
  | 挥手 | 举手 → 左右摆 |
  | 吃醋 | 抱臂扭头“哼” → 睁一只眼偷瞄回来 |
  | 白龙抱枕 | 站着抱住蹭一蹭 → 趴在抱枕上歇一会儿 → 抱着站起来 |
  | 笔记本 | 抱着合上的电脑 → 坐下放在地上 → 掀开 → 打字 → 托腮想一想 → 接着打 → 合上抱起 |
  | 晚安 | 披着星星毯子打瞌睡 → 趴下睡着 → 醒来 |
  | 喝一口 | 捧着马克杯 → 喝一口，两次 |
  | 想一想 | 托下巴 → 竖起手指“想到了”，轻跳 |
  | 伸懒腰 | 双手举高、翅膀张开打哈欠 → 放下来还有点困 |
  | 跳 | 蹲 → 腾空张翅膀 → 落地（点她一下是眯眼笑着轻跳） |

- **和大肥鱼不同的地方**：她的长发、翅膀和裙摆几乎占满整张画，如果像大肥鱼那样让姿势图的各个区域分别挂在头发、裙摆、尾巴的弹簧上，画面会到处被扭，像果冻。所以她的姿势图基本整张一起动：腰带着走，头轻轻点，脚踩在地上不动，只有尾巴尖的小卷单独摆。翅膀是整片绕翅根转，不在中间弯。
- 分层底图和姿势图由图像模型照着尺寸模板在原图上直接改出来，所以站姿和待机模型对得上，误差 1 像素以内。

## 大肥鱼（DeepSeek）的做法

v04 和 v05 第一版都让手臂绕关节转，这套原画撑不住，关节很难看。现在的规则只有一条：

**手臂不转动。手臂姿势不同，就换一张画好的图。**

- **待机和走动**用分层模型：呼吸、眨眼、视线漂移、转头、头发 / 尾巴 / 裙摆 / 耳鳍 / 呆毛的物理跟随、双脚交替迈步。
- **正面的身体和手臂直接取自定稿图**：肩膀在身体两侧，白色肩带褶边露出来，拳头在胸口两边。v04 的分层把手臂涂掉后换成了两只在领结处汇合的大袖子，看起来像手长在胸口，这一层已经弃用。
- **动作**用整张姿势图，每张都绑在同一副骨骼上，所以端着碗的时候照样在呼吸、头发照样在飘：

  | 动作 | 姿势顺序 | 图的来源 |
  | --- | --- | --- |
  | 吃白米饭 | 端碗 → 勺子进碗 → 送到嘴边 → 闭眼嚼，连吃三口 | 11/15 新画 |
  | 电脑开工 | 抱着电脑 → 坐下放好 → 埋头打字 → 做完抬头笑 → 合上 → 抱起 | 11/15 新画 |
  | 敲键盘 | 抱着电脑 → 坐下放好 → 掀开 → 打字 → 合上 → 抱起（电脑斜放，看得见键盘） | v04 关键姿势表 |
  | 思考 | 拳头抵下巴 → 抬眼“唔” → 放下 → 想到了跳一下 | 11/14 新画 |
  | 挥手 | 手举到脸旁，左右摆四下 | 11/14 新画 |
  | 伸懒腰 | 双手举过头打哈欠 → 手放平眯眼 | 11/14 新画 |
  | 抱鲸鱼 | 抱着小鲸鱼左右晃 → 趴到大鲸鱼上眯一会儿 → 起来 | 11/14 新画 |
  | 休息 | 坐着打瞌睡点头 → 躺下睡着 → 醒来 | 11/14 新画 |
  | 跳 | 蹲 → 跳起 → 落地回弹（点她一下也是这个） | 11/14 新画 |

- 姿势之间一律直接切换，不做叠化：两张不同的画叠在一起，哪怕只有几帧也会出重影（两张脸、两只手）。切换落在一次下蹲回弹上，站姿和坐姿、躺姿之间回弹更大；挥手的两张来回换时不回弹。
- 只有「敲键盘」还在用 v04 关键姿势表里的图，用 Real-ESRGAN 动漫模型放大过，蓝色校到了和待机一致；其余新画的十张是照着定稿图的尺寸模板画的，头身比和定稿图一致，只做了抠绿幕和缩放。

`samples/deepseek_v05_demo.mp4` 把全部动作过了一遍。

## 文件

| 路径 | 内容 |
| --- | --- |
| `engine/pet-engine.js` | 通用引擎：网格、蒙皮、弹簧、渲染。不含角色数据 |
| `engine/director.js` | 通用导演：待机（呼吸、眨眼、视线）、走路、播放动作、换图时的回弹。所有角色共用 |
| `characters/deepseek/rig.js` | 骨骼、权重、变形器、弹簧；姿势图的绑定方式 |
| `characters/deepseek/motions.js` | 各动作的姿势时间表，加上她独有的待机和走路细节（尾巴、耳鳍、小拳头） |
| `characters/deepseek/tex/` | 分层模型贴图 |
| `characters/deepseek/tex/poses/` | 24 张姿势图和它们的位置清单 `poses.json` |
| `tools/cut_poses.py` | 从 v04 关键姿势表（米色背景）里抠图 |
| `tools/cut_green.py` | 从绿幕姿势表里抠图并登记位置 |
| `tools/upscale.py` | 放大（需要 torch 和 Real-ESRGAN 动漫权重） |
| `tools/prep_layers.py`、`capture.py`、`poses.py` | 生成分层贴图、导出视频、导出姿势对照表 |
| `tools/check_inbetween.py` | 检查衔接帧：除手臂、道具、表情外，是否和关键姿势一致 |
| `tools/fix_chin.py` | 重建头部图层的下巴边缘，并处理身体图层领口上残留的一段下巴线（头一转就会露出来） |
| `tools/match_colour.py` | 把「敲键盘」这组 v04 旧姿势图的蓝色拉到和待机模型一致 |
| `characters/gpt/` | 白龙娘：rig.js、motions.js、load.js、15 张分层贴图、26 张姿势图 |
| `tools/gpt/cut_layers.py` | 从定稿图和五张分层底图切出白龙娘的分层贴图 |
| `tools/gpt/cut_poses.py` | 白龙娘的绿幕姿势表抠图、登记位置（坐姿、趴姿自动落地对齐） |
| `tools/gpt/strain.py` | 果冻感检查：逐帧光流，只算画面被拉伸和扭曲的程度，整块移动不算 |
| `tools/gpt/head_shift.py` | 量两张姿势图的头差了多少，切换时头会不会跳 |
| `tools/gpt/build_web.py` | 生成网页版（WebP）贴图 |
| `tools/gpt/` 其余 | 尺寸检查、模板合成、单帧截图 |
| `demo_duo.html` | 两人同框演示视频的录制页 |


其他角色：新建 `characters/<名字>/`，各自的 rig.js、motions.js、贴图和姿势图，引擎共用。做法、踩过的坑和完整流程写在 `PLAYBOOK.md`（英文，给做后面四个角色的助手看）。

## 已知的不足

白龙娘：

- 坐下、趴下、站起来是直接换图，靠一次回弹带过去；只有掀开电脑有过渡图。
- 做动作时她的头发和裙摆不飘（这是为了不扭画面），待机和走路时才飘。
- 姿势图比待机模型略软一点。

大肥鱼：

- **姿势切换是换图，不是连续补间。** 这是有意的：之前的补帧失真就出在硬补中间帧上。
- **「敲键盘」这组姿势图还是 v04 的旧画**，颜色校过，但裙子、脸和发梢的画法和待机略有不同，切过去能看出来。
- **姿势图上不能眨眼**（眼睛画死在图里）。
- 眼珠不能单独转动，没有鼠标视线跟随。
- 没有独立的 Windows 桌宠程序，还是网页。

## 新增姿势的流程

1. 生成姿势图：纯绿背景（#00B140），一张两个姿势，人物和定稿图同头身比、760 像素高；站姿用 `python tools/check_proportions.py` 自检。
2. `python tools/cut_green.py <姿势图目录> characters/deepseek/tex/poses`：抠图、缩放、写入 `poses.json`。新表要先在脚本顶部的 `SHEETS` 里登记名字和类型（stand / sit / lie）；切过去如果左右错位，在 `NUDGE` 里补偏移。
3. 在 `characters/deepseek/motions.js` 的 `CLIPS` 里加一段姿势时间表。

## 嵌进别的网站

`web/` 是给网站用的精简版：贴图是 WebP（大肥鱼 2.6 MB，白龙娘 4.2 MB，只下载正在显示的那一位），`web/widget.js` 是全站悬浮桌宠，底部有「换桌宠」，选择会被记住；`web/index.html` 是单独的桌宠页，左上角切换。把 `web/` 整个放到站点的某个目录下，在页面里加一行：

```html
<script defer src="pet/widget.js"></script>
```

它在页面空闲后才加载；手机、阅读页和开启“减少动态效果”时默认收成一个小按钮，点开一次后会记住。
