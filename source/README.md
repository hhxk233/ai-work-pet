# 可编辑分层工程

本版 v04 按用户提供的原设定重新制作主造型；用户确认了脸型、比例和画风方向。`DeepSeek.psd2live` 是完整可编辑绑定工程，可使用 PSD2Live v3.8.0 打开。`layers/` 保留同一套角色的透明图层。

角色采用 1024×1024 模型画布，21 个参数分别控制头、身体、头发、尾巴、腿、抬脚、肩肘腕、眨眼、嘴型、坐姿和袖口遮挡。手腕绕手部锚点独立转动，避免抬手时袖口翻到眼睛上。动作时序和道具锚点在 `../motion.js` 与 `../props.js`。

`../model/cubism/` 附真正的 MOC3 运行模型、CMO3 编辑器导出、配置和纹理。MOC3 已通过官方 Cubism Native Core 加载和实际姿势渲染；CMO3 是工具导出，未在 Cubism Editor 内人工打开验收。继续编辑优先使用已验证的 PSD2Live 工程。
